# Movie-Tracker
A C-based Movie Tracking System that manages movie information using structures, arrays, functions, and file processing.

Overview

This program allows users to manage a collection of movies through a menu-driven interface. Movie information is stored using C structures and can be saved to and loaded from a text file.

Features:

Add movies
Display all movies
Search for movies by title
Update movie information
Delete movies
Save movie data to a file
Automatically load saved movies when the program starts
Automatically save data when the program exits
Input validation
Delete confirmation

Movie Information:

Each movie stores-

Title
Genre
Number of downloads

Technologies:

C
Structures
Arrays
Functions
File I/O
String manipulation
Input validation

File Processing:

Movie information is stored in:

movies.txt

The file uses the following format:

Title|Genre|Downloads

The program automatically creates and updates this file when movie information is saved.

Concepts Demonstrated:

Structures
Arrays
Pointers
Functions
While loops
String handling
Searching
Array element shifting
File reading and writing
Input validation

How to Run:

Clone the repository.
Open MovieTracker.c in a C compiler or IDE.
Compile the program.
Run the executable.
Use the menu to manage movie records.

Purpose:

This project was created to practice core C programming concepts while building a practical application that demonstrates data management and file processing.
